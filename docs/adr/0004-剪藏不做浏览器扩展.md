# ADR 0004：剪藏只做粘贴、公开 URL 与书签小工具

- 状态：已接受
- 日期：2026-11-12
- 相关：`SECURITY.md`

## 背景

印象笔记最标志性的能力是 Web Clipper 浏览器扩展的右键一键剪藏。用户要求「对标印象笔记全套」，但纸间笔记是公开分发的开源桌面应用，扩展需要在各商店上架、维护账号与审核，且会引入持续的权限与合规责任。

此外，本工作区此前的 rustify 项目已确立口径：**开源许可只约束代码，不约束内容与服务；分发比自用风险大得多**，不提供规避技术保护措施的适配。

## 决定

只实现三条真实可用的路径，**界面里不放做不到的假按钮**：

1. 粘贴 HTML（自动清洗脚本与事件属性）
2. 公开 URL 抓取（Rust 侧 `ureq`，拒绝本机 / 内网 / 云元数据地址）
3. 书签小工具（把标题、网址、选中文本复制到剪贴板，回来粘贴）

不做浏览器扩展商店上架，不内置任何第三方站点的解析规则、账号体系或内容适配，不打包第三方内容。

## 理由

1. 三条路径覆盖大多数剪藏需求，且不依赖任何平台授权或商店审核。
2. 书签小工具是浏览器自带能力，不向页面注入常驻脚本，不碰 Cookie / 登录态。
3. 公开分发时，任何「绕过限制获取内容」的适配都会把责任从使用者转移到分发者。

## 后果

- 没有右键菜单一键剪藏，用户要多一步复制 / 粘贴。这个差距在关于弹窗与使用说明里如实写明。
- `fetch_clip` 只抓用户主动输入的公开 URL，且默认拒绝私网地址；用户想剪藏局域网页面会被拦住（刻意的安全默认值）。
- URL 抓取不做登录态、不解析付费内容；遇到复杂页面请用粘贴路径。

## 备选

- 开发并上架浏览器扩展：体验最好，但引入商店账号、审核、权限声明与长期维护，超出个人项目边界。
- 内置常见站点解析器：直接触碰平台条款，且分发风险最高，明确不做。
