# ADR 0006：完整对标印象笔记的信息架构

- 状态：**已接受**（2026-11-12 用户提出「整体还不太多，能不能完全参考一下印象笔记的」）
- 日期：2026-11-12
- 相关：0001（不采用块模型）、0002（纯文本落盘）、0005（Markdown 定位）

## 背景

v1.x 的功能项其实不少（笔记本组、标签、全文搜索、双模式、剪藏、导入导出、提醒、模板、回收站、批量操作），但**信息架构**只有「侧栏树 + 列表 + 编辑器」这一层。用户反馈「整体还不太多」，指的是产品形态离印象笔记还差一截，而不是缺某几个按钮。

对照印象笔记官方帮助中心的 [Sidebar and Navbar Overview](https://help.evernote.com/hc/en-us/articles/221189627-Welcome-to-Evernote-Web) 与 2025 年产品更新，桌面/Web 侧栏的标准区块是：搜索、新建笔记/任务/事件、**首页（小组件）**、**快捷方式**、笔记、**任务**、**文件**、**日历**、**模板**、笔记本、标签、与我共享、空间、回收站、更多、折叠、**自定义侧栏**。搜索侧还有高级语法、保存的搜索、居中搜索弹窗；编辑器侧有自定义默认字体、笔记历史、自定义模板。

## 决策

**在不动存储哲学与编辑器模型的前提下，把信息架构补齐到印象笔记的完整形态。**

具体落地：

| 印象笔记 | 纸间笔记 2.0 | 说明 |
| --- | --- | --- |
| Home 小组件 | 首页仪表盘 | 统计 / 即时贴 / 快捷方式 / 最近笔记 / 待办 / 笔记本概览 / 快速上手 |
| Shortcuts | 快捷方式 | 可固定笔记、笔记本、标签、保存的搜索；右键管理 |
| Tasks / Files / Calendar / Templates | 四个全宽主视图 | 任务汇总所有笔记的待办并回写正文；文件汇总附件；日历按创建日与提醒日回看；模板含「从当前笔记存成模板」 |
| Notebooks / Stacks / 嵌套 Tags | 已有 + 标签树 | `父/子` 形式的标签按前缀分组折叠 |
| 自定义侧栏 | 10 个区块开关 | 设置或侧栏底部进入 |
| 高级搜索 / 保存的搜索 | `tag: notebook: intitle: created: updated: has: is:` | `-` 前缀排除；居中搜索弹窗含最近搜索、语法 chips、实时结果 |
| 自定义默认字体 / 笔记历史 / 模板 | 字体字号颜色下拉、本地历史快照、查找替换、笔记信息面板 | 历史每篇最多 15 版，自动约 1 分钟一版，可恢复 |

## 明确不做（不做假按钮）

这些依赖云端、账号、多人协作或商店分发，与「个人版 / 本地优先 / 无账号」前提冲突：

- 云同步、离线笔记本同步、跨设备冲突合并
- 实时协同编辑、共享链接、Spaces、与我共享、权限管理
- AI 搜索 / AI 转写 / OCR 与手写识别 / 图片内文字检索
- 浏览器扩展商店的 Web Clipper（本版只有粘贴 HTML、公开 URL 抓取、书签小工具）
- 邮件转发入笔记、扫描件、语音笔记、日历账号集成
- 移动端与 Web 多端

**「完全参考」指的是单机版能诚实做到的全部**，不是把云端功能做成点不动的按钮。

## 数据模型影响

`WORKSPACE_VERSION` 从 1 升到 2，新增 `shortcuts / savedSearches / recentSearches / noteHistory / sidebarSections / sticky` 与 4 个 `settings` 缺省值。`Note` 结构**未变**，镜像规则未变，v1 存档直接可开；迁移只补默认值，详见 [data-format.md](../data-format.md)。

## 代价与风险

- 存档从 v1 升到 v2 是一次格式契约变更，已用 6 组迁移断言（含真实旧档）覆盖；旧版程序打开 v2 档不会丢字段，但新功能不可见。
- `noteHistory` 会把历史正文存进 `workspace.json`，附件多的笔记会让存档变大；因此限制每篇 15 版、只在内容变化且距上版超过 1 分钟时自动记。
- 任务视图用字符串解析富文本里的 checkbox，不走 DOMPurify，避免 `input` 被清洗；代价是只支持本项目工具栏插入的 `<li><input type=checkbox>` 结构。
- 前端体积从 476 KB 增到约 558 KB（单文件版），仍在可接受范围。

## 备选方案

1. **只补功能不做首页与全宽视图**：改动小，但「整体感」不变，用户反馈的问题没解决。
2. **改成块编辑器 + 数据库**：Notion / 飞书路线，会推翻 ADR 0001/0002 与「数据自己掌握」这个最大卖点，不采纳。
3. **照搬印象笔记视觉（绿色、图标、间距）**：本项目已有自己的品牌「纸间笔记」，且许可证不保护品牌；视觉只做信息密度对齐，不做像素仿制。

## 结论

架构不变、哲学不变，补齐的是**导航层、聚合视图与检索层**。这一步之后，纸间笔记与印象笔记的差别只剩下「刻意不做的云端能力」。
